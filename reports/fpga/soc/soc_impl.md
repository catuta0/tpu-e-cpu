## Critical path (chosen flow, worst seed 2, post-route) — reports/fpga/soc/critical_path_nwl.txt
21.07 ns = 8.83 ns logic + 12.24 ns routing (=> 47.46 MHz). Inside the CPU: instruction register
`u_cpu.ir` -> decoder / FSM next-state logic (`u_cpu.state`) -> ALU operand select -> 32-bit ALU carry chain
(`u_cpu.alu_q` ALU cells) -> program-counter register (`cpu_dbg_pc` = pc, D input). This is the same class of
path as in RTL-CPU (ir -> decoder -> FSM, 18.77 ns there); the TPU datapath (53-77 MHz alone) is not critical
in the SoC. The default flow's worst path (seed 3, 23.36 ns = 9.73 + 13.63) is the same CPU path ending on the
pc clock enable (critical_path_def.txt). The 10 % margin target needs <= 33.67 ns; slack 12.6 ns.
