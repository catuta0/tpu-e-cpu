# CR-001 — Deterministic (binary) TPU replaces the stochastic TPU as the product design

Status: OPEN (2026-11-04) · Requester: user ("faz o tpu deterministico, ou seja sem bitstreams")
Baseline preserved: stochastic design rev C at git commit d0d6984 (local tag
`sc-tpu-revC`; the proxy refused to push the tag, the commit is on the branch).
The SC-TPU RTL stays untouched in design/rtl/tpu/ as the comparison design; the
new design lives in design/rtl/tpu_det/.

## Motivation
User decision. Engineering note: the SC-TPU needs 10*2^K+368 cycles (2928 at K=8)
and is approximate (94.4 % vs 95.0 % exact, SIMULATION); an exact int8 datapath
with the same weights reaches the exact-arithmetic accuracy (95.0 %, already
computed as the "int8 binary" baseline in SW-01a) in ~10^2 cycles.
